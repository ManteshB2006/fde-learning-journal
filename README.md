# FDE Learning Journal

My 12-month learning journey toward becoming a Forward Deployed Engineer (FDE).

I am building practical skills in software engineering, APIs, databases, AI engineering, system integration, deployment, and customer-focused problem-solving.

## Goals

- Learn concepts and explain them in my own words.
- Practice by writing and testing code.
- Build projects that solve realistic problems.
- Document bugs, debugging lessons, and design decisions.
- Track progress through working software rather than certificates alone.

## Daily Learning Workflow

1. Learn one concept from documentation or a lesson.
2. Write a concise Markdown note in my own words.
3. Practice with code and exercises.
4. Run the code and test edge cases.
5. Record mistakes and how I fixed them.
6. Review changed files before committing.
7. Push meaningful progress to GitHub.

## Daily Note Template

Each daily note should include:

- Date, topic, and time spent
- Definitions and key concepts
- Code examples and expected output
- Practice questions and solutions
- Bugs and debugging lessons
- Real-world applications
- Self-check and next target

## Weekly Review

At the end of each week, I will document:

- What I learned
- What I built
- Bugs I fixed
- Concepts I still need to understand
- Links to commits or projects
- The next week's target

## Principles

- Build instead of only watching tutorials.
- Prefer simple, maintainable solutions.
- Test software and integrations.
- Never commit API keys, passwords, or sensitive information.
- Measure project results honestly; never invent metrics.
- Use certificates to support learning, not replace demonstrated skills.
